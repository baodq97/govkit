# Authoring workflows — runtime contract · the three shapes · validation

Everything needed to emit a valid `.claude/workflows/<name>.js`. Read top-to-bottom. Ground truth
for a real, working file: `.claude/workflows/sdlc.js`.

## 1. The runtime API (globals the Workflow runtime injects — never import them)

| Hook | Signature | Notes |
|---|---|---|
| `agent` | `agent(prompt, opts?) → Promise<any>` | `opts`: `{ label, phase, schema, model, agentType, isolation }`. With `schema` (JSON Schema) the agent returns a validated object; without it, final text. Returns `null` if skipped — `.filter(Boolean)`. |
| `parallel` | `parallel(thunks) → Promise<any[]>` | BARRIER: awaits all. A throwing thunk resolves to `null` (never rejects) — filter before use. |
| `pipeline` | `pipeline(items, ...stages) → Promise<any[]>` | NO barrier. Each stage gets `(prevResult, originalItem, index)`. Returns one entry per item = the LAST stage's result. A throwing stage drops that item to `null`. |
| `phase` | `phase(title) → void` | Groups later `agent()` calls. Inside `pipeline`/`parallel`, pass `phase:` in `opts` instead (a global `phase()` would race). |
| `log` | `log(msg) → void` | Narrator line. **Surface results with this**, not a top-level `return`. |
| `args` | value | The Workflow `args` input, verbatim. Parameterize with it. |
| `budget` | `{ total, spent(), remaining() }` | Token target; `total` is `null` if unset (→ `remaining()` is `Infinity`). Guard budget loops on `budget.total`. |

## 2. Hard constraints

1. **`meta` is a pure literal**, the first statement:
   `export const meta = { name, description, phases: [{ title, detail }] }`. No variables, calls,
   spreads, or template strings inside it. (The `phases: ["A", "B"]` string shorthand `sdlc.js`
   uses also works, but `[{ title, detail }]` is richer — `detail` shows in the progress UI.) Each
   declared title must be **realized** in the body — a `phase("...")` call (top-level) OR a `phase:`
   opt on an agent (inside `pipeline`/`parallel` stages). A pipeline's first phase is usually a
   `phase()` call; later phases are usually `opts.phase`. Both count.
2. **agentType is plugin-namespaced or built-in only** — `swe-flow:implementer`, `swe-flow:reviewer`,
   `swe-flow:doc-keeper`, `Explore`, or a default agent. Project `.claude/agents/` are NOT
   dispatchable from a workflow (verified) — the swe-flow plugin must be installed.
3. **The script sequences; agents do ALL I/O.** No `fs`, `child_process`, or network in the body —
   dispatch an agent to read a file or run `govkit verify`.
4. **Plain JS, ESM.** No TypeScript. `export` + top-level `await` are fine (the dir is ESM).
   **No top-level `return`** — it fails `node --check`; summarize with `log()` instead.
5. **No `Date.now()` / `Math.random()` / argless `new Date()`** — they break resume. Use `args` for
   timestamps; vary randomness by index/label.
6. **Reviewer gates control FLOW only.** `BLOCK` → `throw` to halt; `APPROVE`/`SHIP-WITH-CAVEATS` →
   advance. NEVER `doc.status = ...` or assign an owner — those are human acts (`proposedNextStatus`
   is a proposal). govkit is the gate; the workflow is the accelerant.

## 3. The mandatory fallback header (paste at the top of every generated workflow)

```js
// .claude/workflows/<name>.js — <one-line purpose>. Generated by swe-flow workflow-author.
//
// MANDATORY FALLBACK — workflows are research-preview and globally disableable
// (disableWorkflows / CLAUDE_CODE_DISABLE_WORKFLOWS=1) and cannot be bundled in a plugin.
// If this does not run, drive the same order BY HAND: <the 2–4 step manual sequence, naming the
// swe-flow agents to dispatch>. govkit verify + the PreToolUse hook gate every artifact
// regardless — this workflow is an accelerant, not the source of truth, and never flips a status.
//
// CONSTRAINTS: no filesystem/shell access — dispatched agents do all I/O. agentType is
// plugin-namespaced (swe-flow:*) so the plugin must be installed.
```

## 4. The three shapes — pick ONE

Two families. **Structured** (items known up front) → pipeline or fan-out. **Discovery** (unknown
size) → loop. So the first question is "do I know the work items in advance?"; only then "stages
(pipeline) or dependency waves (fan-out)?". Each skeleton passes `node --check` (ends with `log`).

### a. Pipeline (review → verify) — DEFAULT structured shape
N independent items, each through the same stages. No barrier — item A verifies while item B is
still in review. Reach for a barrier (`parallel` between stages) ONLY when a later stage needs ALL
prior results at once — e.g. "dedup findings across every dimension" or "only report issues seen in
>1 dimension". The `review-changes` example does NOT dedup, so it stays a pipeline.

```js
export const meta = {
  name: "<name>",
  description: "<one line>",
  phases: [{ title: "Review", detail: "one reviewer per item" }, { title: "Verify", detail: "confirm each finding" }],
};
const REVIEWER = "swe-flow:reviewer";
const ITEMS = args?.items || [ /* { key, prompt } */ ];
const FINDINGS = { type: "object", required: ["findings"], properties: { findings: { type: "array",
  items: { type: "object", required: ["title", "file"], properties: { title: { type: "string" }, file: { type: "string" } } } } } };
const VERDICT = { type: "object", required: ["refuted"], properties: { refuted: { type: "boolean" } } };

phase("Review");
const out = await pipeline(
  ITEMS,
  (it) => agent(`You are swe-flow:reviewer (read-only). ${it.prompt} Return findings.`,
    { label: `review:${it.key}`, phase: "Review", schema: FINDINGS, agentType: REVIEWER }),
  (review, it) => parallel((review.findings || []).map((f) => () =>
    agent(`You are swe-flow:reviewer. Try to REFUTE: "${f.title}" in ${f.file}. Default refuted=true if unsure.`,
      { label: `verify:${it.key}`, phase: "Verify", schema: VERDICT, agentType: REVIEWER })
      .then((v) => ({ ...f, survived: Boolean(v) && v.refuted === false })))),
);
const confirmed = out.flat().filter(Boolean).filter((f) => f.survived);
log(`[<name>] ${confirmed.length} confirmed: ` + (confirmed.map((f) => f.file).join(", ") || "none"));
```

### b. Fan-out in dependency waves — structured, with ordering
Disjoint work-packages, some blocking others (`blocks:`), each editing its own paths. This is the
Code phase of `sdlc.js`. The `buildWaves` helper below is the REAL one — copy it verbatim; do NOT
stub it (a stub that returns one big wave silently destroys the dependency ordering).

```js
export const meta = {
  name: "<name>",
  description: "<one line>",
  phases: [{ title: "Code", detail: "file-disjoint implementers in dependency waves" }],
};
const IMPLEMENTER = "swe-flow:implementer";
const REVIEWER = "swe-flow:reviewer";
const REV = { type: "object", required: ["verdict"], properties: {
  verdict: { enum: ["APPROVE", "SHIP-WITH-CAVEATS", "BLOCK"] }, findings: { type: "array", items: { type: "string" } } } };

// Order stories into waves: a story that blocks another lands earlier; within a wave, P0 first;
// same-wave stories must be file-disjoint. Falls back to all-remaining on a dependency cycle.
function buildWaves(stories) {
  const blockedBy = new Map(stories.map((s) => [s.id, new Set()]));
  for (const s of stories) for (const t of s.blocks || []) if (blockedBy.has(t)) blockedBy.get(t).add(s.id);
  const order = { P0: 0, P1: 1, P2: 2 };
  const done = new Set();
  const waves = [];
  let remaining = stories.slice();
  while (remaining.length > 0) {
    const ready = remaining.filter((s) => [...blockedBy.get(s.id)].every((b) => done.has(b)));
    const wave = (ready.length > 0 ? ready : remaining).slice().sort((a, b) => order[a.priority] - order[b.priority]);
    waves.push(wave);
    for (const s of wave) done.add(s.id);
    remaining = remaining.filter((s) => !done.has(s.id));
  }
  return waves;
}

phase("Code");
const stories = (args && args.stories) || [];  // [{ id, priority, blocks:[ids], allowedPaths:[globs] }]
if (stories.length === 0) throw new Error("fan-out needs args.stories: [{ id, priority, blocks, allowedPaths }]");
const waves = buildWaves(stories);
for (let w = 0; w < waves.length; w++) {
  await parallel(waves[w].map((s) => () =>
    agent(`You are swe-flow:implementer. Build ${s.id}. Edit ONLY ${JSON.stringify(s.allowedPaths)}. ` +
      `Write files only; never run pnpm/git/govkit (the lead integrates). Return a files-written summary.`,
      { label: `code:${s.id}`, phase: "Code", agentType: IMPLEMENTER })));
  const gate = await agent(`You are swe-flow:reviewer. Gate wave ${w + 1}: every P0 delivered? allowed-paths honoured?`,
    { label: `gate:w${w + 1}`, phase: "Code", schema: REV, agentType: REVIEWER });
  if (gate.verdict === "BLOCK") throw new Error(`Wave ${w + 1} BLOCKED: ${(gate.findings || []).join("; ")}`);
}
log("[<name>] all waves delivered — lead integrates: pnpm install, govkit verify, commit.");
```

### c. Loop-until-done — discovery shape
Unknown number of items (gaps, bugs, edge cases). Repeat until K consecutive empty rounds (or a
budget). Dedup against everything ever seen, NOT against a confirmed subset — else rejected items
reappear and the loop never converges.

```js
export const meta = {
  name: "<name>",
  description: "<one line>",
  phases: [{ title: "Hunt", detail: "repeat until dry" }],
};
const REVIEWER = "swe-flow:reviewer";
const GAPS = { type: "object", required: ["gaps"], properties: { gaps: { type: "array",
  items: { type: "object", required: ["id"], properties: { id: { type: "string" }, detail: { type: "string" } } } } } };

phase("Hunt");
const seen = new Set();
const found = [];
let dry = 0;
while (dry < 2) {                                    // two empty rounds in a row => done
  const r = await agent(`You are swe-flow:reviewer (read-only). Find gaps not in this list: ` +
    `${JSON.stringify([...seen])}. Return {gaps:[{id, detail}]}.`,
    { label: `hunt:${found.length}`, phase: "Hunt", schema: GAPS, agentType: REVIEWER });
  const fresh = (r.gaps || []).filter((g) => !seen.has(g.id));
  if (fresh.length === 0) { dry++; continue; }
  dry = 0;
  for (const g of fresh) { seen.add(g.id); found.push(g); }
  log(`[<name>] ${found.length} so far`);
}
log(`[<name>] done — ${found.length}: ${found.map((g) => g.id).join(", ")}`);
```

## 5. Validation checklist (deterministic — run after writing, fix until clean)

```bash
node --check .claude/workflows/<name>.js                              # MUST exit 0
grep -nE 'export const meta = \{' .claude/workflows/<name>.js         # one, near the top
# meta MUST be a pure literal — the runtime rejects concatenation (+), template interpolation
# (${}), or spreads (...) inside it, and node --check does NOT catch this. This scans the whole
# meta block; a hit INSIDE a quoted string value (e.g. "10+ files", "A → B...") is a false alarm —
# read the flagged line before acting, and never weaken the check to silence one. Keep meta values
# free of those characters (reword) rather than disabling the grep.
awk '/export const meta = \{/,/^\};/' .claude/workflows/<name>.js | grep -nE '\+|\$\{|\.\.\.' && echo 'FAIL: meta not a pure literal (verify it is not inside a string value)' || echo 'meta literal OK'
grep -noE 'phase\("[^"]+"|phase:[[:space:]]*"[^"]+"' .claude/workflows/<name>.js  # covers every meta title
grep -nE 'agentType:[[:space:]]*"' .claude/workflows/<name>.js | grep -vE 'swe-flow:|Explore'        # empty
grep -nE 'Date\.now|Math\.random|child_process|from "fs"|^[[:space:]]*return ' .claude/workflows/<name>.js  # empty
grep -nc 'govkit verify\|swe-flow:reviewer' .claude/workflows/<name>.js   # >= 1 (a gate exists)
grep -nc 'MANDATORY FALLBACK' .claude/workflows/<name>.js                 # 1
```

All pass → ready to run. Don't weaken a check to make it pass; fix the script. (Edge case: a
workflow meant to `return` to a parent `workflow()` won't pass `node --check` — validate it by
piping through `(async () => { … })()` first.)

## What does NOT belong here

A brand-new specialist agent, a new skill, a generated agent *team*, or an N-pattern coordination
taxonomy. Compose the three existing agents into one of these three shapes — or tell the user the
request is bigger than a workflow.
